# My Key Website

A responsive, single-file educational portfolio website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new repository (for example, `my-key`).
3. Upload `index.html` to the repository's root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.

## Notes
- The site is responsive and its navigation, lesson dialogs, sample quizzes, and demo forms work in the browser.
- Login/sign-up forms are demonstrations only. Real accounts, saved progress, and server-side contact delivery require a backend.
